# Avatar icon / 头像图标

`icon.png` is the avatar icon used by DSH Share and its DeepSeek Harness Share menu entry. The artwork was created for this project by its maintainer, contains no third-party material, and is distributed under the same MIT license as the rest of the project.

`icon.png` 是本项目采用的头像图标，由本项目维护者为本项目创作，不含第三方素材，与本项目其余部分一样以 MIT 许可证分发。

The native macOS app and share extension use the same artwork; this copy is its squircle crop for the DeepSeek Harness plugin list and the marketplace tile.
